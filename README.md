## 📦 Add-ons disponibles
 
### 1. 🔧 MultiExport Tools
Exporta el objeto 3D activo en múltiples formatos de manera simultánea con un solo clic.
 
**Formatos soportados y para qué sirve cada uno:**
 
| Formato | Extensión | ¿Para qué se usa? |
|---------|-----------|-------------------|
| Wavefront OBJ | `.obj` | Es el formato más universal. Compatible con casi cualquier programa de diseño 3D. Ideal para intercambiar modelos entre diferentes softwares. |
| Autodesk FBX | `.fbx` | Muy usado en motores de videojuegos como Unity y Unreal Engine. También guarda animaciones y materiales junto con el modelo. |
| STL | `.stl` | Es el formato estándar para impresión 3D. Si quieres imprimir un objeto en una impresora 3D, este es el formato que necesitas. |
| GLTF 2.0 | `.glb` | Pensado para la web y la realidad aumentada. Es compacto y eficiente, ideal para mostrar modelos 3D en páginas web o apps móviles. |
 
**Características:**
- Panel integrado en la barra lateral (tecla N) → pestaña **MultiExport**
- Selector de carpeta de destino personalizable
- Crea la carpeta automáticamente si no existe
- Usa el nombre del objeto como nombre base de los archivos
---
 
### 2. ⚡ Quick Actions Panel
Panel de atajos rápidos con las acciones más usadas en Blender, agrupadas en secciones para mayor comodidad.
 
**Acciones disponibles:**
 
| Sección | Botones |
|---------|---------|
| Transformaciones | Resetear posición, rotación y escala |
| Objeto | Duplicar, enfocar cámara, eliminar |
| Agregar malla | Cubo, Esfera, Cilindro |
| Render | Render rápido |
 
---
 
## 🚀 Instalación
 
Los pasos son los mismos para ambos add-ons:
 
1. Descarga el archivo `.py` del add-on que deseas instalar
2. Abre Blender y ve a **Editar → Preferencias → Complementos**
3. Haz clic en **"Instalar..."**
4. Selecciona el archivo `.py`
5. Activa el complemento marcando la casilla ✅
---
 
## 📍 Ubicación en Blender
 
| Add-on | Ubicación |
|--------|-----------|
| MultiExport Tools | Vista 3D → Barra lateral (N) → pestaña **MultiExport** |
| Quick Actions Panel | Vista 3D → Barra lateral (N) → pestaña **Quick Actions** |
